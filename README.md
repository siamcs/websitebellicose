# Hermano Synergy Ltd — Official Website

🌐 **Live Website**: [https://siamcs.github.io/websitebellicose/](https://siamcs.github.io/websitebellicose/)

Modern, high-performance institutional procurement and global trading platform website for **Hermano Synergy Ltd.**

## Key Features
- **Modern UI & Aesthetic**: Dynamic interactive Three.js 3D globe, glassmorphic design, and dark/light mode toggle.
- **Institutional Procurement**: Live tender opportunities, interactive tender search and category filters.
- **RFQ Basket & Management**: Real-time quotation basket with PDF quotation generator and direct inquiry modal.
- **Live Currency Converter**: Dual currency support (USD / BDT / EUR).
- **Interactive Bangladesh Operations Map**: Real-time operational hub indicators (Chittagong Port, Mongla, Dhaka HQ).
- **Future Plan & Growth Pipeline**: Strategic milestones roadmap for 2026–2030.
- **Client Portal & Security**: Client verification, demo login modal, and encrypted messaging form.

## Tech Stack
- Vanilla HTML5 / CSS3 / JavaScript (No heavy runtime dependencies)
- Three.js (Interactive 3D particle globe)
- Lucide Icons & Google Fonts (Manrope, Inter, JetBrains Mono)
